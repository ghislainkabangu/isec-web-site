# ISEC MEP.SARL — Site Web Vitrine

## 📌 Présentation

**ISEC MEP.SARL** est un site web vitrine conçu et développé pour présenter l’entreprise, ses activités, ses services et ses réalisations.

Le projet a été réalisé dans le but de mettre en pratique mes compétences en développement web, notamment en **HTML, CSS et JavaScript**, ainsi que mes connaissances en conception d’interfaces et en déploiement web.

## 🎯 Objectifs du projet

* Présenter l’entreprise et son activité de manière professionnelle.
* Mettre en avant les différents services proposés.
* Présenter les réalisations de l’entreprise.
* Faciliter l’accès aux informations de contact.
* Proposer une navigation simple et intuitive.
* Adapter l’interface aux différents supports.

## 🛠️ Technologies utilisées

* **HTML5** — Structure et organisation des pages
* **CSS3** — Mise en forme et conception de l’interface
* **JavaScript** — Interactions et fonctionnalités dynamiques
* **Git** — Gestion des versions
* **GitHub** — Hébergement du dépôt et gestion du projet
* **GitHub Pages** — Déploiement du site

## 📂 Contenu du site

Le site comprend notamment les sections suivantes :

* Accueil
* À propos
* Services
* Réalisations
* Équipe
* Localisation
* Contact

## 💻 Compétences mises en pratique

À travers ce projet, j’ai travaillé sur :

* La conception d’une interface web
* L'intégration HTML/CSS
* Le développement avec JavaScript
* La structuration et l’organisation du contenu
* La navigation entre les différentes sections
* L’adaptation de l’interface aux différents supports
* La gestion du projet avec Git et GitHub
* Le déploiement d’un site web avec GitHub Pages
